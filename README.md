## Why Jupyter Notebooks?

Jupyter Notebooks are one of the most powerful and widely-used tools in data science, scientific computing, and education. Here's why they matter:

### Interactive Computing
Jupyter allows you to write and execute code in small, isolated cells — making it easy to explore data, test ideas, and iterate quickly without re-running an entire script.

### Visualization & Storytelling
Notebooks seamlessly combine live code, rich text (Markdown), equations (LaTeX), and visualizations (charts, graphs, images) in a single document. This makes it straightforward to tell a data-driven story.

### Reproducibility
By capturing both the code and its output together, notebooks make it easy for others (and your future self) to reproduce results exactly — a cornerstone of good scientific and analytical practice.

### Education & Documentation
Notebooks are widely used in academia and training because they blend explanation with execution. You can document your reasoning alongside your code, making notebooks ideal for tutorials, walkthroughs, and teaching materials.

### Language Agnostic
Despite the name, Jupyter supports over 40 programming languages (Python, R, Julia, Scala, and more) via interchangeable **kernels** — making it a versatile tool across disciplines.

### Shareable & Accessible
Notebooks can be shared as `.ipynb` files, rendered directly on GitHub, or published via services like [kaggle](https://kaggle.com "https://kaggle.com") — ensuring they are accessible to anyone, anywhere, without a local setup.

## Getting Started

### View Online
All notebooks render directly on GitHub. Simply click on any `.ipynb` file in this repository to view it in your browser.

### Run Locally
To run the notebooks on your own machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/shainemeister/jupyter-notebooks.git
   cd jupyter-notebooks
   ```

2. **Install Jupyter**
   ```bash
   pip install notebook
   ```

3. **Launch Jupyter Notebook**
   ```bash
   jupyter notebook
   ```
